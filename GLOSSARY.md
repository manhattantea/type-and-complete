# Curriculum How-To

A shared domain vocabulary for the comment- and drill-driven learning workspaces (`odin_how_to/`, `python_how_to/`, and `tracy_how_to/`), modeled on the direct conversational commentary of `CodingTemplateExamples/how_to/`.

## Language

**Primer**:
A self-contained single-file learning unit inside a workspace folder.
_Avoid_: Lesson file, exercise file, sample

**Lab**:
A multi-file learning subfolder for larger programs or concepts that span multiple files, modules, packages, or build targets.
_Avoid_: Module folder, project lesson

**Scaffold**:
Minimal pre-written starter code (roughly 5–20% of an unfilled Primer or Lab, including convenience syntax examples when introducing new constructs).
_Avoid_: Template, skeleton, worked anchor

**Drill**:
A conversational `#` or `//` comment guiding hands-on coding practice and IDE autocompletion inside an open section or signature stub.
_Avoid_: Prompt, TODO, cue, exercise
